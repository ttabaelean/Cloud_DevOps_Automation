## 📖 과정 소개

본 과정은 **클라우드 인프라 구축부터 애플리케이션 배포 자동화까지** DevOps의 핵심 기술을 단계적으로 학습하는 강의입니다.

가상화와 Linux, Docker를 시작으로 AWS 클라우드, Kubernetes, GitHub Actions, Argo CD를 학습하며, 최종적으로 **CI/CD 및 GitOps 기반의 클라우드 DevOps 자동화 파이프라인**을 구현합니다.

이론과 Hands-on Labs를 통해 클라우드 환경에서 애플리케이션을 구축·배포·운영하는 과정을 이해하는 것을 목표로 합니다.

## 🔄 최종 DevOps 자동화 파이프라인

```text
Developer
    │ git push
    ▼
GitHub (Source Code)
    │
    ▼
GitHub Actions (CI)
    │ Build & Docker Image
    ▼
Amazon ECR
    │
    ├── 이미지 저장
    │
    ▼
GitOps Repository (이미지 태그 변경)
    │
    ▼
Argo CD (CD)
    │
    ▼
Amazon EKS (Kubernetes)
    │ ECR에서 이미지 Pull
    ▼
Spring PetClinic
```

- **CI – GitHub Actions:** 소스 코드 빌드, 컨테이너 이미지 생성 및 ECR Push
- **CD – Argo CD:** GitOps 저장소의 변경 사항을 감지하고 EKS에 자동 배포
- **운영:** 배포 상태 점검, 장애 분석 및 복구
